# Caesar Cipher Using Python

## Overview
This project was completed as part of my Prodigy InfoTech cybersecurity internship. It demonstrates the Caesar Cipher, a classical encryption technique that replaces each alphabetic character with another character shifted by a fixed number of positions.

The program supports encryption and decryption using a specified shift value.

## Objectives
- Understand the fundamentals of cryptography.
- Implement a classical substitution cipher using Python.
- Learn how encryption and decryption work.
- Explore the limitations of traditional encryption techniques.

## Technologies Used
- Python 3

## Features
- Encrypts text using a specified shift value.
- Decrypts text using the corresponding shift value.
- Preserves spaces and punctuation, if supported by the implementation.
- Handles alphabetic characters according to the implemented logic.

## How It Works
1. The user enters the text to be processed.
2. A shift value determines how many positions each letter moves through the alphabet.
3. Encryption shifts letters forward through the alphabet.
4. Decryption reverses the shift to recover the original text.

For example, with a shift value of 3:

- **Original text:** HELLO
- **Encrypted text:** KHOOR
- **Decrypted text:** HELLO
